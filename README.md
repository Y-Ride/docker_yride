# docker_yride
This is for development of the yride golf cart using docker containers for drivers



Drivers need to be added as submodules. Run the following in the docker_yride directory so that the .gitmodules file will automatically update.
`git submodule add -b <branch name> <git repo url> <Location to put new submodule>'

To update any submodules run:
'git submodule update --init --recursive'
